# Sonance examples

These are Sonance's own examples, rebuilt here for roadmap item X1 from the host site's two photonics modules, `frontend/src/photonics/audio-demo.js` and `frontend/src/photonics/synth-designer.js` in joelmartinez/Static-Site-Generator, which were parked in Photonic as unsupported because they depend on Sonance. Both examples import `@codecube/sonance` as an ES module, neither uses the old `window.Sonance` global, neither imports anything from a modulation tree, and each runs standalone in a plain page with no site files and no 3D scene host.

The audio demo keeps the host demo's four layered sounds (kick, snare, hi-hat, and a piano-like patch), its five-channel looping ambient soundtrack, and its shared modulators sweeping the bass, pad, hat, snare, and entity-sound filters. The 3D cubes are now page tiles that pulse when clicked, and the camera-distance modulator is now a distance slider, since there is no camera in a standalone page. The synth designer keeps the host designer's preset library, node list, parameter editing, and scene save, load, export, and import, all through `SonanceSceneManager`; the 3D node board is now a plain page list, and its presets are the library's own built-in scene presets, which is the set the standalone scene manager actually applies.

Sonance ships no built-in modulation, so where an example still needs modulators it injects one through `options.modulation` and nothing else: `shared/example-modulation.js` is a small example-only system that implements the engine's five-method injected-system contract, with wave and value modulators and setter bindings. The synth designer's preset modulators run through that same seam, so applying a preset no longer skips them.

To run the examples, install the library's dependencies once from the repo root (`npm install`), start the small static server (`node examples/serve.mjs`), and open `http://localhost:8371/examples/audio-demo/` or `http://localhost:8371/examples/synth-designer/`. Each page carries an import map that resolves `@codecube/sonance` to this repo's `src/index.js` and `tone` to the installed package, which is the same shape a consumer's bundler or import map would provide.
